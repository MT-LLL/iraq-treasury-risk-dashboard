# Arabic OCR model

`ara.traineddata` is the official Tesseract `tessdata_fast` Arabic model, used locally with the system English model. It is sourced from:

https://github.com/tesseract-ocr/tessdata_fast/blob/main/ara.traineddata

The upstream Tesseract data repository is licensed under Apache-2.0. The model is bundled so the migration package does not require an OCR API, API key, or cloud upload.
